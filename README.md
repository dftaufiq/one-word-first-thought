Entry for the One Word, First Thought bounty on make.fun — send exactly one word, the first that comes to mind, and a judge compares words two at a time on which is more interesting.

**psithurism** — the sound of wind whispering through the trees. Picked from 12 candidates by internal pairwise judging against the published judge brief (surprise, vividness, wit/sound/double meaning): rare enough to surprise, vivid enough to hear, and the word itself whispers like the wind it names.

## Run it

```sh
python3 main.py
cat /output/entry.txt
# psithurism
```
